# TeXPress Studio

Desktop LaTeX IDE & academic publishing suite for Windows with live PDF.js preview, bidirectional SyncTeX, multi-root & BibTeX compilation, and VS Code-style workspace ergonomics.

## Key Features
- **Smart LaTeX Engine Auto-Detection:** Automatically routes between `pdflatex`, `xelatex`, and `lualatex` via magic comments, `\documentclass` options, and loaded packages, with automated multi-pass `bibtex` citation resolution.
- **Live PDF.js Preview & Bidirectional SyncTeX:** Continuous high-DPI PDF rendering, selectable text layer, clickable TOC/citation links, and `Ctrl+Click` / `Ctrl+Alt+J` source-to-PDF navigation.
- **VS Code-Style Multi-File Tabs & Explorer:** Preview (italic) vs. permanent tabs, `Ctrl+P` Quick Open, per-tab cursor/scroll memory, inline file/folder/standalone-document creation, and center-pane PDF & image viewers.
- **Academic Authoring Tools:** Equation, Figure, and `booktabs` Table wizards, BibTeX citation picker, Greek & Math symbols dock, manuscript word-count breakdown, inline spellcheck with right-click suggestions, and Recent Folders + Windows Taskbar Jump List.

## Development
```bash
npm install
npm start
```
